# Bandeiras locais

Os arquivos de bandeiras devem ser adicionados nesta pasta com nomes
normalizados por código ISO 3166-1 alpha-2, por exemplo `br.svg` e `jp.svg`.

Antes de incluir arquivos definitivos, registrar no README principal a fonte,
a versão e a licença/atribuição correspondente.

O mapa do protótipo já reconhece `BR`, `AR`, `CL`, `CO` e `PE`. A ausência das
imagens ainda não impede a validação geométrica, mas precisa ser resolvida
antes da entrega da mecânica completa de arrastar bandeiras.
